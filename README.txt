Movie Library
Автор: Роттер Виолетта Эдуардовна
Дата создания: 7.05.2026

Описание
Приложение на Python с использованием Tkinter для управления коллекцией фильмов. Поддерживает:
- Добавление фильма (название, жанр, год выпуска, рейтинг)
- Табличный вывод списка
- Фильтрацию по жанру и году выпуска
- Сохранение и загрузку данных в формате JSON
- Простую валидацию ввода

Как использовать
1. Запуск:
   python movie_library.py
2. Добавление фильма:
   - заполните поля и нажмите "Добавить фильм"
3. Фильтрация:
   - выберите жанр из списка или введите год выпуска в соответствующее поле
4. Сохранение/Загрузка:
   - нажмите "Сохранить в JSON" или "Загрузить из JSON"
5. Гит:
   - git init
   - git add .
   - git commit -m "Добавлено приложение Movie Library"

Примеры данных
[
  {"title": "Inception", "genre": "Sci-Fi", "year": 2010, "rating": 8.8},
  {"title": "The Godfather", "genre": "Crime", "year": 1972, "rating": 9.2}
